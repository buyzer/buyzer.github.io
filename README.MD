# Buyung Abadi — Resume Website
 
Personal resume site for a Senior WordPress Engineer with 10+ years of experience in custom website development. Static site built with Astro and Tailwind CSS, hosted on GitHub Pages.
 
**Live site:** [buyzer.github.io](https://buyzer.github.io)
 
## Tech stack
 
- [Astro](https://astro.build) (static output, no client-side framework)
- [Tailwind CSS](https://tailwindcss.com)
- GitHub Pages + GitHub Actions for hosting and deploys
